Ejecuta el agente

Elige un artista y pulsa Analizar. El agente valida la entrada, consulta la fuente simulada, reconstruye el histórico la primera vez, calcula la tendencia y emite alertas.

folk_analytics — salida del agente 
Cargando el intérprete de Python…
Sobre los datos: la fuente es una API de streaming simulada. Es una decisión de alcance deliberada: mantiene el proyecto reproducible y sin credenciales. La simulación es determinista — para un artista y una fecha dados siempre devuelve el mismo valor. Esa propiedad es justamente la que hace que las tendencias detectadas signifiquen algo en lugar de medir ruido.

El ciclo del agente

Percibir → procesar → actuar. Cada fase vive en su propio módulo.

01 · PERCIBIR

Entrada y consulta

Valida el nombre introducido y consulta la fuente de datos, con reintentos y retroceso exponencial ante fallos transitorios.

agent.py api/

02 · PROCESAR

Memoria y análisis

Persiste la instantánea en disco y analiza el histórico acumulado: estadística descriptiva, cambio porcentual y regresión lineal.

storage/ analytics/

03 · ACTUAR

Alertas y reporte

Evalúa la tendencia contra los umbrales configurados, genera las alertas pertinentes y compone el reporte final.

analytics/alerts.py reports/

Lo que separa esto de un script de consulta puntual es la memoria. Cada ejecución deja un rastro que las siguientes aprovechan. Sin histórico no hay tendencia que detectar, solo ruido.

Arquitectura

El proyecto programa contra una interfaz, nunca contra una implementación concreta.

folk_analytics/
├── agent.py          ciclo percibir → procesar → actuar
├── cli.py            menú interactivo y modo demo
├── config.py         parámetros ajustables
├── logging_setup.py  logging con fallback ASCII
├── api/
│   ├── base.py       interfaz StreamingClient
│   ├── models.py     ArtistData
│   ├── simulated.py  fuente determinista
│   └── spotify.py    fuente real (futuro)
├── analytics/
│   ├── metrics.py    estadística descriptiva
│   ├── trends.py     detección de tendencias
│   └── alerts.py     motor de alertas
├── storage/
│   └── json_store.py histórico y watchlist
└── reports/
    └── console.py    renderizado

Cómo ejecutarlo en tu equipo

Requiere Python 3.10 o superior. El núcleo funciona solo con la librería estándar.

# clonar
git clone https://github.com/armando4322-2/UPY-PROGRAMMING-PROJECT-ARMANDO-MOLINA-Q2-2026-.git
cd UPY-PROGRAMMING-PROJECT-ARMANDO-MOLINA-Q2-2026-

# ejecutar
python run.py                 # menú interactivo
python run.py --demo          # demostración completa
python run.py -a "AURORA"     # un artista y sale

# tests
python -m pytest tests/ -v

# regenerar esta página
python tools/build_web.py
