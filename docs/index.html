Ejecuta el agente

Elige la fuente y un artista, y pulsa Analizar. El agente valida la entrada, consulta la fuente, guarda la instantánea, analiza el histórico acumulado y emite alertas. Con la fuente simulada dispone de 30 días de histórico; con datos reales lo acumula desde tu primera consulta.

Top 10 canciones

Ordenadas por el índice de popularidad que publica Deezer, que no es un número de reproducciones. Pulsa ▶ para oír 30 segundos.

Fuente simulada. Genera series temporales deterministas: para un artista y una fecha dados siempre devuelve el mismo valor. Esa propiedad es la que hace que las tendencias detectadas signifiquen algo en lugar de medir ruido. Trae 30 días de histórico desde el primer momento, así que sirve para demostrar la detección de tendencias.
Live stats · datos reales. Cada métrica procede de la fuente que realmente la publica: seguidores y álbumes de Deezer, fotos e identificadores de Spotify, país y géneros de MusicBrainz.

La popularidad es un índice calculado, no una métrica oficial. Ninguna plataforma la publica ya: Spotify dejó de exponerla a las aplicaciones nuevas. Se deriva de un dato que sí es real —el rango que Deezer asigna a cada canción— con una fórmula explícita: media(rango del top 10) ÷ 10.000. Se usa la media y no el máximo para que un único éxito viral no describa mal a todo el repertorio.

El histórico se acumula desde hoy. Ninguna API pública devuelve los seguidores que un artista tenía hace treinta días, así que el agente los mide día a día. Hasta que haya suficientes puntos la tendencia dirá «datos insuficientes», que es la respuesta correcta y no un fallo.

El ciclo del agente

Percibir → procesar → actuar. Cada fase vive en su propio módulo.

01 · PERCIBIR

Entrada y consulta

Valida el nombre introducido y consulta la fuente de datos, con reintentos y retroceso exponencial ante fallos transitorios.

agent.py api/

02 · PROCESAR

Memoria y análisis

Persiste la instantánea en disco y analiza el histórico acumulado: estadística descriptiva, cambio porcentual y regresión lineal.

storage/ analytics/

03 · ACTUAR

Alertas y reporte

Evalúa la tendencia contra los umbrales configurados, genera las alertas pertinentes y compone el reporte final.

analytics/alerts.py reports/

Lo que separa esto de un script de consulta puntual es la memoria. Cada ejecución deja un rastro que las siguientes aprovechan. Sin histórico no hay tendencia que detectar, solo ruido.

Arquitectura

El proyecto programa contra una interfaz, nunca contra una implementación concreta.

folk_analytics/
├── agent.py          ciclo percibir → procesar → actuar
├── cli.py            menú interactivo y modo demo
├── config.py         parámetros ajustables
├── logging_setup.py  logging con fallback ASCII
├── api/
│   ├── base.py       interfaz StreamingClient
│   ├── models.py     ArtistData
│   ├── simulated.py  fuente determinista
│   └── spotify.py    fuente real (futuro)
├── analytics/
│   ├── metrics.py    estadística descriptiva
│   ├── trends.py     detección de tendencias
│   └── alerts.py     motor de alertas
├── storage/
│   └── json_store.py histórico y watchlist
└── reports/
    └── console.py    renderizado

Cómo ejecutarlo en tu equipo

Requiere Python 3.10 o superior. El núcleo funciona solo con la librería estándar.

# clonar
git clone https://github.com/armando4322-2/UPY-PROGRAMMING-PROJECT-ARMANDO-MOLINA-Q2-2026-.git
cd UPY-PROGRAMMING-PROJECT-ARMANDO-MOLINA-Q2-2026-

# ejecutar
python run.py                 # menú interactivo
python run.py --demo          # demostración completa
python run.py -a "AURORA"     # un artista y sale

# tests
python -m pytest tests/ -v

# regenerar esta página
python tools/build_web.py
